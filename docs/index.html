About the data

An independent campus explorer inspired by the Tabata Flood & Infrastructure Explorer. This is not an official UDSM service.

Campus infrastructure

OpenStreetMap snapshot retrieved on 2 October 2026. Features are selected within the full Chuo Kikuu triangle in OpenStreetMap (relation 5608085). Chuo Kikuu is mapped as an administrative subward; this study extent is not a surveyed university ownership boundary. Roads are clipped to this boundary; buildings are selected by a point inside each footprint.

Counts represent mapped OSM objects. Missing features, unnamed buildings and duplicated facility records are possible. “Unspecified” means the source records a building without a specific type.

Flood analysis

No flood hazard dataset is bundled. Load a WGS 84 (EPSG:4326) GeoJSON Polygon or MultiPolygon, Feature or FeatureCollection exported from QGIS. Maximum file size: 5 MB. Mixed geometry collections are not accepted.

A building is exposed if any part of its footprint intersects a supplied flood polygon. An amenity is exposed if its mapped point is within or on a flood polygon. Analysis runs locally in your browser; files are not uploaded. Results are not a flood forecast or a safety assessment.
